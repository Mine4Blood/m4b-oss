Getting Started

New to Mine4Blood Open Source? Here is how to get started:

1. Explore our projects — Visit the Projects page to see what we are working on.

2. Join the community — Sign up on our community forum to connect with other contributors and stay up to date.

3. Set up your environment — Clone the repository you want to contribute to and follow the setup instructions in its README file.

Contributing

We welcome contributions from everyone. Here are some guidelines:

Fork & Branch — Fork the repository and create a feature branch for your changes.

Code Style — Follow the existing code style and conventions of the project.

Pull Requests — Submit a pull request with a clear description of your changes. All PRs are reviewed by maintainers before merging.

Issues — Found a bug or have a feature request? Open an issue on the project's GitHub repository.
